# market-research
מחקר שוק עבור אפליקציית כוח מוח, שנועדה לתת לעובדים ומשפחתם בכל הגילאים (הורים וילדים, מבוגרים ונכדים)- גישה נוחה ופרקטית להתמיד באימונים קצרים וחוויתיים עם משימות מוחיות. אימוני כוח מוח מבוססים על שילוב בין משימה פיזית, קוגניטיבית ומנטלית, הפוגה קצרה שמייצרת הקשבה לגוף, תנועה, חיבור וזמן איכות.
